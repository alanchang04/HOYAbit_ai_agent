## Stage 4 — Dynamic Evidence Weight Engine（示範：ATR）

> 對應 [[07_流程圖迭代定案]] Round 7 的 Evidence Weight Engine。
> ATR 的 Market Regime 若用 ATR 自己的歷史序列判斷會自我循環，
> 改用「降息與否」（FOMC 利率決議方向）當外部依據，避免自己量自己。

```
weight:
  factor_id: ATR

  ####################
  # Prior Weight（來自 Knowledge，慢變動）
  ####################
  historical_predictability:
    ic:                          # 原始 IC 值，直接用（例如 Funding=0.11／OI=0.18／Social=0.02）
    hit_rate:                    # HitRate 只當資格門檻：要顯著偏離 0.5 才計入，不顯著則 historical_predictability 視為 0
    normalization:                # 待定，Ken 之後校準（暫定固定基準線性正規化，IC_ref 待抓）
  source_reliability:            # 待來源可信度分級表定案
  historical_support:            # 對應 references 欄位怎麼轉成分數，待定

  ####################
  # Dynamic Modifier（來自今日市場，快變動）
  ####################
  market_regime:
    classification:              # rate_cutting／rate_hiking／rate_hold 三態，資料來源＝FOMC 利率決議方向
    modifier_rule:                # rate_cutting = rate_hiking ＞ rate_hold ＞ baseline；降息/升息同幅放大，維持不變放大幅度較小，實際乘數待回測校準
  time_horizon_match:            # ATR 窗口（例如14天）跟分析視野對不對得上，待定
  context:                       # 具體指什麼還沒定義
  cross_source_consensus:        # 單一來源時 default 行為，待定
  freshness:

  final_weight:                  # = prior_weight × context_modifier，公式骨架，尚未實作
```
