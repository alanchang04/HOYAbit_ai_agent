# Feature 模板（Statistical／Event／Sentiment 三型）

> 對應 [[09_權重改版草案]] 的 Factor Interpreter 三型分流。

## Statistical Factor（示範：funding_rate）

```

  factor: funding_rate

  # Raw
  current_value:
  previous_value:
  delta:

  # Relative
  percentile:
  z_score:

  # Trend
  slope:
  slope_7d:
  slope_30d:

  roc_1d:

  # Statistics
  rolling_mean:
  rolling_std:
  rolling_max:
  rolling_min:

  # Quality
  missing_ratio:
  sample_size:
```
